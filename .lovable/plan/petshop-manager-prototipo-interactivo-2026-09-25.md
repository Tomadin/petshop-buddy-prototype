# PetShop Manager — prototipo interactivo

## Resultado
Una aplicación administrativa responsiva, en español, con navegación lateral y cuatro módulos completos alimentados por datos de ejemplo en memoria.

## Alcance
- Crear una identidad visual profesional en azul petróleo, menta y neutros claros, con tipografía limpia e iconos Lucide.
- Construir un marco multitienda con selector de local, navegación lateral colapsable y cabecera adaptable a móvil.
- Implementar el dashboard con métricas, alertas de stock y próximos pedidos.
- Implementar inventario con búsqueda, filtros, alta, edición, detalle y eliminación simulada.
- Implementar suscripciones con filtros, alta, cambio de estado y frecuencias de 15, 30, 45 o 60 días.
- Implementar notificaciones y pagos simulados mediante modales y mensajes de confirmación.
- Mantener toda la información en estado local; al recargar, vuelven los datos de demostración.
- Añadir metadatos propios de PetShop Manager y validar la experiencia en escritorio y móvil.

## Detalles técnicos
- React 19 y Tailwind CSS 4 con tokens semánticos globales.
- Componentes reutilizables para botones, campos, modales, etiquetas y tablas.
- Sin servicios externos, cuentas, backend ni base de datos.
