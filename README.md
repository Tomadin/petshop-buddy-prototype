# PetShop Manager Pro

Actúa como un diseñador UI/UX y desarrollador Frontend senior experto en React y Tailwind CSS. Necesito que crees una maqueta interactiva de alta fidelidad (Mockup/Prototipo) sin backend ni base de datos para un sistema multitenant de gestión para PetShops llamado "PetShop Manager".

La aplicación debe utilizar estados locales en React (React State / Mock Data) para simular todas las interacciones de manera fluida, dinámica y responsiva para presentársela a un equipo de trabajo.
